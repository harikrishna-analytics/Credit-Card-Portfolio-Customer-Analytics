# 📌 Project Overview

The **Credit Card Portfolio & Customer Analytics** project is an end-to-end business analytics solution designed to analyze customer and credit-card portfolio characteristics.

The project uses **SQL for data validation, preparation, transformation, and business analysis**, followed by **Tableau for interactive visualization and business storytelling**.
